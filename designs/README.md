# Profile README designs

Earlier versions and alternative designs for this profile. The live design is the
[shipping label](../README.md) at the repository root. Open a folder to see that design rendered.

| Design | What it is |
| --- | --- |
| [v1-original](v1-original) | First version: plain sections, coloured badges and a logo table |
| [v2-revamp](v2-revamp) | Bonsai beside the intro, one row of dark badges, inline company logos |
| [v3-diagrams](v3-diagrams) | Centred header, keycap stack, request sequence and commit-to-production diagrams |
| [ruby-class](ruby-class) | Profile written as a Ruby class |
| [hero-diagram](hero-diagram) | Centred header with a stack flowchart |
| [spec-sheet](spec-sheet) | Fact table with the stack as labels |
| [label](label) | Shipping label with the "Shipped from Bangalore" stamp |
| [label-ai](label-ai) | Shipping label with an "AI assisted" sticker and a Claude Code band |
| [terminal](terminal) | Animated terminal that types out the profile |
| [terminal-ai](terminal-ai) | Terminal running `claude`, with a streamed answer |
| [metro](metro) | The stack drawn as a transit map, with light and dark versions |

The SVG images come from [`gen_svgs.py`](gen_svgs.py). Run `python3 gen_svgs.py designs`
from the repository root to rebuild them, including `assets/label.svg` for the live profile.
